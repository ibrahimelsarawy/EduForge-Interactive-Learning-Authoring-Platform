# EduForge Content Creator Guide

## Getting Started
Open the EduForge Module Builder and type a clear title for your lesson at the top of the page. The builder is designed so that you can work in small pieces. Each piece is called a **block**. A block can be a paragraph, image, quiz, calculator, callout, progress tracker, badge, or another learning activity. Start by choosing a block from the left panel. You can also press `/` outside a text field and search by name, such as `/calc` for the financial calculators. Add one block at a time and use the live preview on the right to see the learner experience.

## Block Types Overview
**Rich Text:** Use this for lesson explanations, headings, lists, quotes, links, and short examples. For example, introduce the 50-30-20 budgeting rule before asking a quiz question.

**Image:** Use this for diagrams or illustrations. Always write meaningful alternative text so learners using assistive technology understand the image.

**Video Embed:** Use a supported YouTube or Vimeo lesson video when a concept is easier to demonstrate visually.

**MCQ Quiz:** Use this for a multiple-choice knowledge check. Add two to six choices and mark the correct choice or choices.

**True/False Quiz:** Use this for quick statements such as “Interest is charged only on the original investment.”

**EMI Calculator:** Use this in home-loan or vehicle-loan lessons so learners can explore monthly repayments.

**SIP Calculator:** Use this in investment lessons to demonstrate how regular monthly investing can grow over time.

**Compound Interest:** Use this to explain how interest can grow when returns are added back to the investment.

**Callout:** Use this to highlight a warning, tip, important idea, or useful financial reminder.

**Divider:** Use this to separate lesson sections visually.

**Accordion / FAQ:** Use this for common questions without making the lesson page too long.

**Progress Tracker:** Use this to show where a learner is in a multi-step lesson.

**Achievement Badge:** Use this to reward a milestone, such as completing a savings activity.

**Code Snippet:** Use this when a lesson needs a structured JSON, JavaScript, Python, or SQL example.

**Animated Concept Explainer:** Use this for a short sequence of three to ten steps, such as how compound interest grows.

## Using Calculators
For an EMI calculator, enter the loan amount, annual interest rate, and repayment period. The monthly result is shown in Indian number formatting. For a SIP calculator, enter the amount invested every month, expected annual return, and number of years. For compound interest, enter the starting amount, rate, duration, and how often interest is added. Check the preview after configuration and try different values as a learner would.

## Creating Quizzes
Add a quiz block, write the question, and provide the answer choices. Mark at least one correct answer. Use the module feedback setting to decide whether feedback appears immediately or at the end. Choose the points for each question and preview the learner flow before exporting.

## Arranging Your Module
Drag the grip icon to move a block. You can also focus a block and use Alt+Up or Alt+Down. Use Duplicate to create a copy and Delete to remove a block. If you make a mistake, use Undo. Undo and Redo buttons show whether an action is currently available.

## Previewing Your Module
Use the device buttons to switch between desktop, tablet, and mobile widths. Test calculators and quizzes directly in the preview. Use the preview dark-mode button to check the alternative appearance.

## Exporting and Importing
Export creates a portable save file for the complete module. Import restores a previously saved module after checking that its structure is valid. If import reports a problem, correct the field named in the message and try again.

## Troubleshooting
**I deleted something.** Use Undo immediately. The builder keeps a history of recent changes.

**My image is not accepted.** Use JPG, PNG, WebP, or SVG and keep the file under 5MB.

**Export is not working.** Check the title, quiz answers, calculator ranges, and required image descriptions. Export is blocked when a serious problem could create an unusable module.

**My block disappeared in preview.** Check the block visibility button. Hidden blocks stay in the editor but do not appear to learners.

**I cannot move a block.** Check whether it is locked. Unlock it before editing or rearranging it.
